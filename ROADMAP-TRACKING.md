## 🔄 Adjustment Protocol

If actual metrics are 20%+ below targets:

1. **Diagnose** (same day)
   - What specifically is underperforming?
   - Is it a system issue (posts not publishing) or a strategy issue (content not resonating)?

2. **Pivot** (within 24h)
   - Content issue? Change 1 theme and test for 48h
   - Traffic issue? Increase posting frequency by 1x
   - Conversion issue? Improve CTA clarity

3. **Measure** (after 1 week)
   - Did change improve metrics?
   - If yes, scale it
   - If no, revert and try different change
